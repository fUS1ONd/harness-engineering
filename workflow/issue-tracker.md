# Локальный трекер задач (`.scratch/`)

Спецификации и тикеты усилия хранятся локально в `.scratch/<feature-slug>/` целевого репозитория (вне git / `.gitignore`), чтобы не загрязнять историю проекта черновыми планами.

## Структура

- `.scratch/<feature-slug>/spec.md` — спецификация усилия.
- `.scratch/<feature-slug>/issues/<NN>-<slug>.md` — по одному файлу на тикет (нумерация с `01`).
- `.scratch/<feature-slug>/hod.md` — текущее состояние усилия (фронтир, что в работе, где пауза), ведёт только оркестратор.
- Завершённые усилия переносятся в `.scratch/_arhiv/`.

## Поля и статусы тикета

| Поле / статус | Значение |
|---|---|
| `Status: ready-for-agent` | Все `Blocked by:` имеют статус `done`, а `## Образец` одобрен владельцем |
| `Status: in-progress` | Взят в работу; ниже указывается `Branch:` |
| `Status: needs-owner` | Требует решения или одобрения образца владельцем |
| `Status: done` | Влито в ветку усилия |
| `Blocked by:` | Номера блокирующих тикетов через запятую или `None` |
| `Owner gate:` | Шаг, который выполняет или проверяет только владелец |

## Обязательные разделы тикета

- `## Образец` — что увидит пользователь (см. [ui-preview.md](ui-preview.md)), либо явно «нет, внутреннее».
- `## Не делать` — ограничения рамки задачи.
- `## Answer` — ответы оркестратора/владельца на возникшие развилки.
- `## Comments` — ход обсуждения.
